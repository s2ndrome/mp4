# SEOL MP4

사진에 음악을 넣고, 음향 효과와 사진 효과를 입혀 **MP4 영상**으로 저장하는 정적 웹 도구입니다.
모든 처리는 브라우저 안에서만 하고, 사진·음악은 어디에도 올라가지 않습니다.

## 기능

- **사진**
  - 파일 고르기 / 끌어다 놓기 / **붙여넣기(Ctrl+V · ⌘V)** / 이미지 주소로 넣기
  - 여러 장이면 순서대로 넘어감 (부드럽게 · 바로 넘김), 순서 바꾸기
  - 꽉 채우기 / 전체 보이기(흐린 사진 · 단색 배경), 확대·위치 조절 (미리보기 드래그 · 휠)
  - 글자 넣기: 글꼴 6종, 위치·정렬, 서서히/타자 치듯 나타나기
- **사진 효과**
  - 필터 14종: 흑백, 세피아, 빈티지, 필름, 바랜 사진, 차갑게, 따뜻하게, 선명하게, 몽환, 새벽 블루, 노을, 밤, 핑크빛 + 밝기·대비·채도·색온도·바램·빛 번짐 직접 조절
  - 움직임 7종: 천천히 줌인/줌아웃, 좌우 이동, 둥실둥실, 손떨림, 비트 펄스(음악 크기에 맞춰), 기울기
  - 효과 18종: 필름 노이즈, 먼지·스크래치, VHS 비디오, RGB 분리, 글리치, 주사선, 깜빡임, 빛 번짐, 빛망울, 비네팅, 눈, 비, 반짝이, 하트, 꽃잎, 음파 라인, 이퀄라이저, 시네마 바
  - 캠코더 날짜 표시, 화면 페이드 인/아웃
  - 효과마다 강도 조절, 여러 개 동시 사용
- **음악**
  - mp3 · m4a · wav · ogg · flac, 동영상 파일의 소리
  - 파형 보며 구간 자르기 (15초 / 30초 / 1분 / 전체 / 재생 위치부터)
  - 볼륨, 페이드 인/아웃
- **음향 효과** (여러 개 겹치기, 켠 순서대로 적용, 효과마다 강도 조절)
  - LP 지지직, 물속에 잠긴, 콘서트장, 퍼지는 몽환, 성당·큰 홀, 옆방에서, 멀리서 들리는, 옛날 라디오, 전화기 너머, 확성기, 카세트 테이프, 로파이, 동굴 메아리, 8D 회전, 물결 트레몰로, 보컬 줄이기, 고장난 스피커, 창밖 빗소리
  - 속도(0.5×~1.6×, slowed · 나이트코어), 저음·고음, "slowed + reverb 한 번에"
- **저장**
  - 9:16 · 4:5 · 1:1 · 16:9 · 사진 비율, 720p / 1080p, 24 / 30fps
  - 크롬·엣지·사파리: WebCodecs로 **H.264 + AAC MP4**를 곡 길이보다 빠르게 만듦
  - 지원하지 않는 브라우저: 실시간 녹화(MediaRecorder)로 대신 저장
  - 모바일에서는 공유 버튼으로 사진 앱에 바로 저장
- 설정(효과·필터 등)은 이 브라우저에 자동 기억

## 배포 (GitHub Pages)

빌드 과정 없이 파일 그대로 배포됩니다.

1. 저장소 **Settings → Pages**
2. **Source**: `Deploy from a branch`, **Branch**: `main` / `/ (root)` → Save
3. 잠시 후 `https://s2ndrome.github.io/mp4/` 에서 열립니다.

로컬에서 보려면: `python3 -m http.server` 후 `http://localhost:8000`
(ES 모듈을 쓰기 때문에 `index.html`을 더블클릭해서 여는 방식으로는 동작하지 않아요.)

## 파일

- `index.html` – 화면
- `style.css` – 스타일 (4layout과 같은 무드)
- `js/app.js` – 상태, 입력, 미리보기, 붙여넣기·끌어다 놓기
- `js/image-fx.js` – 사진 필터·움직임·효과 그리기 (미리보기와 저장이 같은 코드)
- `js/audio-fx.js` – Web Audio 음향 효과 그래프 (미리듣기와 저장이 같은 코드)
- `js/exporter.js` – 오디오 분석, WebCodecs 인코딩 + MP4 묶기, MediaRecorder 대체 경로
- `vendor/mp4-muxer.js` – MP4 컨테이너 만들기 (MIT, v5.2.1)
